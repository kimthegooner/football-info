# 아스날 · 맨유 팬 허브

프리미어리그 두 클럽(아스날 / 맨체스터 유나이티드)의 경기·순위·통계·선수단·이적시장·여론을
한 페이지에 모은 비공식 팬 사이트입니다.

**단일 HTML 파일**로 동작합니다. 빌드 과정이나 외부 의존성이 없고,
선수 사진 58장도 파일 안에 내장되어 있어 인터넷 없이 열어도 그대로 보입니다.

## 구성

헤더의 스위처로 **아스날 ↔ 맨유**를 전환하며, 각 팀마다 10개 탭을 제공합니다.

| 탭 | 내용 |
|---|---|
| 홈 | 개막 카운트다운, 최근 경기, 다가오는 일정, 핵심 브리핑 |
| 경기 | 프리시즌·리그 결과와 일정 (전부 한국시간 기준, 현지 시각 병기) |
| 순위표 | EPL 순위 및 상위권 승점 비교 |
| 통계 | 시즌 지표 대시보드 (레이더 차트, 순위 분포도, 주요 기록) |
| 선수단 | 1군 스쿼드 사진·상세 프로필, 감독 소개, 전술, 베스트 11 |
| 다음 상대 | 개막 상대 분석과 관전 포인트 |
| 칼럼 | 해외 매체 칼럼 요약 (발행일 기준 정렬) |
| 기자회견 | 감독·선수 인터뷰 요약 |
| 팬 여론 | 분위기 → 핫토픽 → 국내 여론 → 해외 여론 |
| 이적시장 | 확정 영입·방출과 루머 (신뢰도 구분 표기) |

## 표기 원칙

- 모든 일정은 **한국시간(KST)** 기준이며 현지 시각을 함께 적었습니다.
- **오피셜과 루머를 반드시 구분**하고, 루머는 신뢰도를 함께 표기합니다.
- 확인되지 않은 정보는 지어내지 않고 "미확정"으로 남깁니다.
- 커뮤니티 여론은 원문을 그대로 인용하지 않고 순화해 요약합니다.

모든 내용은 공개된 보도를 요약한 것이며, 상표와 이미지의 권리는 각 권리자에게 있습니다.
